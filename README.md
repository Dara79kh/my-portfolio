## 🚀 Featured Projects

Here are some of my selected software development projects.

### 01. Salon Booking System

A full-stack salon booking application built with a microservices architecture. It connects customers with salon service providers and provides a platform for managing appointments, services, and bookings.

**Technologies:**
React.js, Java, Spring Boot, Microservices, Docker, PostgreSQL.

**Key Focus:**

- Microservices architecture.
- User authentication and role-based authorization.
- Salon and service management.
- Appointment and booking management.
- REST API integration.

### 02. Food Delivery – E-Commerce Platform

A full-stack online food delivery application designed to provide customers with a convenient food ordering experience through an interactive and responsive interface.

**Technologies:**
React.js, Node.js, Express.js, PostgreSQL, Prisma ORM, JWT.

**Key Focus:**

- User authentication and authorization.
- Food browsing and product management.
- Shopping cart and order management.
- Backend API development.
- Database integration using Prisma ORM.

**Live Demo:** https://food-delivery-phi-pink.vercel.app/

### 03. SquareCG – Intelligent AI Assistant

An AI-powered conversational application designed to provide an interactive AI chat experience through a modern and responsive user interface.

**Technologies:**
React.js, Vite, Node.js, Express.js, Prisma, PostgreSQL, Gemini API.

**Key Focus:**

- AI-powered conversational interface.
- Real-time response streaming using SSE.
- User authentication.
- Modern chat interface.
- AI API integration.
- Persistent conversation management.

**Live Demo:** https://square-cg.vercel.app/

### 04. Personal Portfolio Website
